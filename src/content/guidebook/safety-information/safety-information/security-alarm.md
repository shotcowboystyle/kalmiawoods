The house is equipped with an alarm which we would suggest you set each time you leave the house. This is a friendly community and break-ins are very rare, but it's always worth taking the extra precaution when it takes less than 10 seconds to set!

Jamie will provide you with the alarm code on check-in (it is changed for each guest).

The alarm is located next to the coat rack that's to the right of the front door as you enter. To set the alarm, simply:

- Press the button with the green house icon on it
- Key in the code
- Leave the property (don't worry - you've got 60 seconds before the alarm enables!)

To disable the alarm:

- Press the button with the unlocked padlock icon
- Key in the code

If you forget the code or don't manage to disable the alarm on time, don't panic! Simply give us a call and we'll walk you through the next steps.
